\# Project 12 – Land Surface Temperature (LST) Analysis



\## Overview



This project analyzes Land Surface Temperature (LST) across Córdoba, Spain using Landsat 8 Collection 2 Level 2 imagery in Google Earth Engine.



The workflow extracts surface temperature, computes descriptive statistics, classifies temperature into five categories, calculates the area of each class, and exports GeoTIFF outputs for further GIS analysis.

\## Methods



1\. Load Córdoba administrative boundary.

2\. Filter Landsat imagery.

3\. Create median composite.

4\. Convert thermal band to Celsius.

5\. Calculate temperature statistics.

6\. Classify temperature into five classes.

7\. Calculate area of each class.

8\. Export GeoTIFF outputs.
